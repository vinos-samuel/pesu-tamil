# Pesu Tamil (பேசு தமிழ்)

*"Pesu" means "speak".* A gamified web app that teaches English-speaking kids (5–14) to speak and understand everyday Tamil in 15–20 minutes a day.

I'm building it because my own son is growing up English-first, and most Tamil apps teach script before speech. This one starts with talking.

## Status
Pre-build. Product, game design, session flow, stack and v1 content (46 phrases) are locked. App code is next.

## Design in one minute
- Speak first, read later: listen, repeat, use the phrase in a tiny scene.
- Short daily sessions, with nests of related phrases instead of grammar lessons.
- Native-speaker audio recorded from family.
